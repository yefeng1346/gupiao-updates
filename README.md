# 本地股票板块复盘工具：更新发布仓库

用户可直接从[GitHub发布页](https://github.com/yefeng1346/gupiao-updates/releases/latest)的Assets下载完整ZIP，不要选择“Source code”。若旧版已经打不开，推荐关闭软件后解压到新文件夹，仅复制原目录的`.env`、`data`、`reports`，不要复制旧EXE或`_internal`；先保留原目录。仍能打开的版本可在线检查更新；遇到旧版HTTP 500或启动错误需手动升级一次。

最新版本：[1.7.5 ETF日期对齐、免费净值切换及名单删除](v1.7.5-release-notes.md)。修复ETF名单日期与份额发布日期不同导致补缺中断，按实际共同日期补缺并标注旧记录；新增免费净值来源自动／东方财富／新浪切换，两个来源分别缓存，份额仍取交易所。成交额通道失败不再中断净值补缺。历史候选新增删除所选名单及二次确认，不影响其他名单、行情和复盘日记。保留ETF日／5日榜、多日流入筛选、选股难度及Windows启动兼容修复。升级保留本机Key、配置、历史数据库、公式、复盘日记和选股结果；公开包不含用户凭据或数据，源码仍在私有仓库。免费来源可能延迟或限流，不保证每次全量成功。

source目录保留历史源码快照；当前版本源码不放在公开更新仓库。维护者在私有开发仓库构建新版本，用户通过GitHub Release下载完整更新包。

资金归档与历史同步说明：[维护文档](source/tools/FLOW_ARCHIVE.md)。云端公开采集默认关闭，必须先确认来源分发授权和云端可用性。当前没有已部署的公共历史数据集，历史接口不可用的过去日期不能凭空补出。
