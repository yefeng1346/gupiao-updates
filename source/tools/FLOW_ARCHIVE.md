# 1.6.0 逐日资金档案

默认免费本地模式：软件打开时，每个已确认交易日15:10后采集概念/行业全量榜单。
跨窗口SQLite租约避免重复定时任务；成功后10分钟再复核，最多6次尝试、2次成功。
15:00来源时间只有在该快照实际采集于收盘缓冲之后才可归档；旧盘中快照不会因为晚上重开而变为收盘记录。
当天重复采集覆盖同一主键，变动前值保留在capital_flow_revisions。显示前20不限制保存范围。

用户一键更新：获取完整当前榜 → 可选历史库同步 → 只从本地逐日档案计算。
不等待push2his历史下载；高级补缺保留旧限流/冷却/取消任务。
10日筛选只接受最近10个实际交易日完整数据；缺失不作零、不用旧日期凑数。
清理显示缓存不删除逐日档案；高级删除档案会先备份，不能删除正在运行的任务。

## 中央采集与镜像

先确认来源数据的保存与分发授权，再设置GitHub仓库变量
`FLOW_REDISTRIBUTION_AUTHORIZED=true`。未确认授权时必须保持未设置，工作流不会采集/公开数据。
GitHub工作流模板为tools/flow-collection.yml；发布仓库安装至.github/workflows。
其source目录只存程序源码，不存.env、API Key或用户数据库。
每个交易日多时段尝试；定时任务仍可能延迟，不能作为唯一无故障来源。
启用前应在云端连续验证实际收盘日期、完整板块数量和失败提示，不能只看任务绿色状态。

本地采集器：`python -m tools.collect_daily_flow --output PRIVATE_PATH`。
公开采集需显式增加`--public --redistribution-authorized --base-url HTTPS_BASE`。
可重复传入--base-url以生成同一SHA256文件的镜像地址；这不会自动创建镜像托管服务。
本机定时调用亦可，电脑关闭时不采集；本程序不私自注册Windows计划任务。

客户端`FLOW_FEED_URLS`为逗号分隔的HTTPS索引地址，默认空。
未确认数据授权、镜像未部署、云端未验证时不预填虚构地址。
索引schema=1, source=eastmoney, metric=main_net_inflow, unit=CNY，必须声明redistribution_authorized=true。
每个条目包含sector_type、trade_date、sha256和urls。客户端逐地址验证大小、SHA256、日期、金额、数量、重复代码及收盘时间，然后事务写入。
坏文件不覆盖原记录；同一天上游修订可再次同步，记录前值。
SHA256保证文件一致性，不代替发行者身份签名，索引只信任已配置的发布方HTTPS地址。
