# 本地股票板块复盘工具

这是一个本地浏览器工具：行情由 AkShare、efinance 或通达信协议/本地文件获取并保存到 SQLite，排名和 RPS50 在本地计算，DeepSeek 或 Doubao-Seed-2.1-pro 根据摘要生成结构化详细复盘。完整的数字复盘不依赖 LLM。

## 启动

```powershell
cd D:\Codes\gupiao
.\start.ps1
```

然后打开 <http://127.0.0.1:8000/>。
启动脚本会在依赖文件变化时自动安装/更新依赖；如果本工具已占用 8000 端口且配置未变化，会复用现有服务；如果 `.env` 已变化，会安全重启本工具的旧进程使配置生效。

## 使用流程

1. 选择“概念板块”“行业板块”或“全部板块（概念+行业）”。选择全部板块时，工具会一次同步两类板块，并在报告区域分别提供两份报告切换，不会把两种代码体系混在一起计算排名。
2. 第一次测试时把“最多板块数”设为 10；确认正常后改为 0 获取全部板块。
3. 如果只想同步指定板块，可以在“板块代码/名称”中输入代码或精确名称，多个值用逗号或换行分隔。
4. 搜索板块时先点击“更新板块目录”，再按代码或名称搜索；结果会显示代码体系和是否已有本地历史行情。点击“填入同步筛选”可以把结果直接带入同步条件。
5. 点击“同步收盘数据”，再点击“读取本地报告”。
6. 页面顶部“报告日期（可选）”可以切换已有交易日；切换后会重新读取该日期的全部榜单和总结，留在“最新可用日期”即可看最新完整报告。历史序列表上方的“查找板块名或代码”可以直接定位并高亮板块；点击第 1 个序列表中的板块名称，可展开该板块当前公开返回的全部股票和 ETF。
7. 在“实时行情”面板勾选自动刷新，可对当前板块全集按实时涨跌幅排名；代码留空时分析当前板块，输入代码时查询指定个股/板块。
8. 需要清空时点击“清空本地数据”。它只删除 SQLite 中的行情和同步记录，不删除板块目录、代码或 `.env`。
9. 页面顶部“复盘模型”可以在 DeepSeek V4 Pro 和 Doubao-Seed-2.1-pro 之间切换；DeepSeek 使用 `ARK_API_KEY`，Doubao 优先使用 `ARK_DOUBAO_API_KEY`，留空时回退到 `ARK_API_KEY`。
10. “通达信公式选股”区域预置了你提供的公式；可以新建多个自定义公式并自行命名，内置公式不能删除但可另存为副本；选股结果会保存到历史列表，也可以单独手动删除某条结果。选择 5 分钟、15 分钟、30 分钟、60 分钟、日线或周线后点击“开始选股”。分钟周期使用 `TDX_ROOT` 下的本地 `.lc5` 5 分钟线合成，日线/周线使用个股 `.day` 文件，先计算 OBV/资金条件，再验证 `FINANCE` 基本面条件。

## 综合候选股票与AI解读

页面底部新增独立区域，单来源和左右对比模式均可使用。选择板块报告来源、板块范围及候选数量，点击“生成候选股票＋AI解读”。程序先展示候选，再在同一行右侧逐只加载解释；取消自动AI解读可只生成免费规则结果。

- 数据前提：所选来源的最新收盘板块报告、唯一可核对的板块成员，以及覆盖同一报告日的通达信个股日线（至少61条）。用户需在通达信下载个股日线，板块日线不能代替个股数据。历史日期不作为回测入口。
- 默认从得分最高的五个板块取成员，最多展示十只股票。板块分来自主线分组、RPS、排名改善和本地已保存的三日资金；个股分来自均线趋势、涨幅与量比。相关排名窗口只取最大值，同一股票不因多个板块重复加分。默认最低日成交额两千万元，短期五日涨幅超过百分之三十剔除；这些是观察规则，不是已验证的盈利策略。
- 板块资金只作板块参考，不代表个股资金。缺失资金不填零、不加分；可勾选要求完整三日正净流入，也可叠加已保存的日线/周线技术公式。包含FINANCE的公式须继续用原公式选股功能，候选池不冒充已核验财务。
- 使用现有模型和Key，无新增数据订阅。AI不能改变候选名单或得分，只返回带证据引用的定性解读；结构错误、代码不符、无效证据、数字或交易承诺会被拒绝。候选仍保留，用户可逐只重试。结构校验不能保证模型每句话都正确，仍需核对实际证据。
- 候选和成功解读保存到本机；重开只恢复结果，不自动发起付费请求。相同事实与模型复用缓存，多窗口共享任务与请求锁。取消不能撤销已发送的模型请求，也不能退还可能产生的费用。
- 暂未核验财务、公告、复权口径与下一交易日可成交性；名单仅为观察候选，分数不是上涨概率，不构成买卖指令。

验收：`python -m unittest discover -s tests -p 'test_*.py'`；`node tests/test_candidate_ui.cjs`。`tests/candidate_browser_fixture.py` 使用隔离数据库、模拟行情和模拟AI，在端口59517提供真实网页/API验收，不会调用付费模型。功能已随1.6.3发布，用户可通过软件检查更新升级。

## 固定十个复盘模块（规则说明）

网页和 `/api/report` 会始终返回：

1. 20 日历史前 300 序列表：按最新排名展示每个板块在历史日期的排名、RPS50、收盘价、涨跌幅、成交额；最后一列显示最近 3 个交易日第一天到最新一天的名次变动。
2. 单日强势前进 TOP 榜。
3. 单日走弱 TOP 榜。
4. 最近 5 日强势前进 TOP 榜。
5. 最近 5 日走弱 TOP 榜。
6. 百名内最近 5 日强势前进 TOP 榜。
7. 最近 10 天至少有 6 天名次前进榜：取最近 10 个可用交易日的 9 个相邻区间，要求排名严格前进不少于 6 天。
8. T0/T1/T2 主线最终格局。
9. 核心趋势总结。
10. 操作策略模板：核心底仓、轮动加仓、短线博弈、坚决回避、现金/等待。

名次箭头含义：`↑n` 为前进 n 名，`↓n` 为下降 n 名，`→0` 为无变化。

T0/T1/T2 规则固定为：

- T0：排名 ≤ 10 且 RPS50 ≥ 85。
- T1：排名 11–30 且 RPS50 ≥ 75。
- T2：排名 31–50 且 RPS50 ≥ 65，或最近 5 日排名前进 ≥ 15。

## 数据与 LLM 说明

- 行情历史、成交额、排名和 RPS50 保存在 `data/gupiao.db`。
- 普通行情接口通常不提供截图中的“原始板块排名/RPS50”，工具会使用收盘价和涨跌幅本地计算，并在“数据状态”中标记为“本地计算”。如果有外部程序/API提供原始快照，可通过网页导入或 `POST /api/import-snapshot` 原样写入 `source_rank` 和 `source_rps50`；工具不会从涨跌幅猜测截图原值。
- 报告会自动避开只返回少量板块的提前交易日，并提示缺失或不完整日期。
- 板块目录和历史行情是两层数据：目录用于代码/名称搜索，行情用于报告。清空行情后仍可搜索已保存的目录。
- 当“最多板块数”大于 0 或填写了指定代码时，同步优先使用本地目录缓存，避免每次重复请求完整远端目录；“最多板块数=0”才会刷新完整目录。目录实时接口失败时，已有缓存仍可继续同步。
- 板块同步返回“全部成功/部分成功/失败”状态，并保留每个失败板块的原因；部分板块失败不会伪装成完整成功。
- 个股实时行情优先使用腾讯批量接口，失败时尝试东方财富逐股票接口，最后才尝试有硬超时的全市场快照；因此不再强依赖单个全市场快照节点。
- `GET /api/quote` 保留上游原始字段，同时提供稳定字段 `symbol`、`name`、`price`、`pct_change`、`amount` 和 `data_source`，调用方不需要适配中文列名。
- `GET /api/realtime-board` 会读取当前板块全集，按实时涨跌幅计算 `realtime_rank` 和 `realtime_strength`，并返回上涨/下跌宽度与中位涨跌幅；`realtime_strength` 是盘中百分位分，不冒充历史 RPS50。
- efinance 如果目录或历史接口返回异常，会尝试使用本地目录和 AkShare 备用链路；这两种行情源都依赖公开接口，不能替代有 SLA 的商业行情服务。
- 第 1 个历史序列表的板块名称支持点击展开成分股/ETF。网络数据源优先使用东方财富公开板块成分股接口；选择通达信数据源且本机存在板块文件时，优先读取通达信本地成员关系，网络不可用时仍可显示成员代码。
- 公式选股当前是对这条公式的明确实现，不是完整的任意通达信公式解释器。分钟周期依赖 `TDX_ROOT` 下的 `.lc5` 文件，日线/周线依赖个股 `.day` 文件；所有周期都依赖 `FINANCE(9/22/25/43/57)` 财务字段，财务字段缺失时会保守地不计入结果，不会把未知数据当成通过。
- 如果需要完全离线验证财务条件，可在工具目录创建 `data\tdx_finance.csv`，表头使用 `code,finance_9,finance_22,finance_25,finance_43,finance_57`，数值按通达信 `FINANCE()` 口径填写。
- 公共行情网络请求使用 `MARKET_HTTP_MODE=auto`：有 HTTP(S) 代理变量时优先走代理，否则直连，失败会切换另一条链路；页面“网络诊断”按钮可以区分接口不可达和 API Key 问题。
- 截图中的 `880xxx` 属于通达信板块指数代码。设置 `MARKET_PROVIDER=tdx` 后，工具会优先读取 `TDX_ROOT` 下的 `T0002\hq_cache\tdxzs.cfg` 和 `vipdoc\*\lday\*.day`，本地文件不存在时再尝试通达信行情协议。
- 如果要固定使用通达信普通版本地数据，设置 `MARKET_PROVIDER=tdx_standard`。该模式只读取普通版本地板块目录和历史日线，不会因为网络/VPN自动切换到远程历史数据；实时行情仍需要通达信协议或网络。
- 页面顶部的“行情数据源”可以直接切换 `通达信网络数据` 和 `通达信普通版（本地）`；切换只影响之后的目录、同步和实时行情请求，不需要修改 `.env` 或重启。`MARKET_PROVIDER` 仍作为默认数据源。
- 页面中的完整十模块由本地程序生成；其中“百名内最近5日强势前进 TOP 榜”只保留报告日最新排名前100名，“最近10天至少有6天名次前进榜”统计最近10个可用交易日的9个相邻区间，缺失数据的区间不计入前进天数；DeepSeek 只接收摘要并生成结构化详细复盘，避免把完整历史矩阵交给模型重新计算。
- 火山方舟配置从 `.env` 读取，默认模型为 `deepseek-v4-pro-ga-260813`；页面还提供 `Doubao-Seed-2.1-pro` 选项，模型 ID 由 `ARK_DOUBAO_MODEL` 配置，默认是 `doubao-seed-2-1-pro-260628`。DeepSeek 使用 `ARK_API_KEY`，Doubao 优先使用 `ARK_DOUBAO_API_KEY`，留空时回退到 `ARK_API_KEY`；不要把 API Key 写入代码或提交到版本库。
- DeepSeek 请求默认绕过系统 HTTP(S)_PROXY 直连火山方舟，避免本地 VPN 代理端口导致 Python HTTPS 握手超时；如确实需要代理，可在 `.env` 设置 `ARK_USE_ENV_PROXY=true`。
- DeepSeek 详细复盘默认通过 `thinking.type=disabled` 关闭深度思考，避免长时间生成思维链；可用 `ARK_THINKING_TYPE=auto/enabled` 切换，但响应可能明显变慢。
- DeepSeek 请求默认读取超时为 180 秒，可用 `ARK_TIMEOUT_SECONDS` 调整（10-180 秒）；超时会明确提示网络/VPN问题，不会伪造报告。
- DeepSeek 详细复盘默认最多输出 4096 tokens（工具当前上限），可用 `ARK_MAX_TOKENS` 调整；如果模型仍达到上限，页面会明确提示“输出可能被截断”。
- 交付环境建议保持 `MARKET_PROVIDER=akshare`；`efinance` 作为兼容模式，会优先复用已验证的 AkShare/逐股票备用链路，避免其全市场接口无超时导致页面长时间卡住。

## 通达信代码体系

如果你老爸需要和截图完全一致的 `880xxx` 板块指数，请在 `.env` 设置：

```dotenv
MARKET_PROVIDER=tdx_standard
TDX_ROOT=D:\通达信安装目录
```

`TDX_ROOT` 应指向通达信普通版根目录，而不是 `T0002` 子目录。目录内通常应有 `T0002\hq_cache\tdxzs.cfg` 和 `vipdoc\sz\lday\sz880xxx.day`。普通版尚未完成板块数据更新时，目录或历史行情可能为空。选择 `tdx_online` 时则跳过本地文件，直接使用通达信网络协议。

## API

- `GET /api/health`
- `POST /api/catalog/sync`：更新当前行情源的板块目录
- `GET /api/search?sector_type=concept&query=CXO`
- `POST /api/sync`：字段 `sector_type`、`calendar_days`、`max_sectors`、可选 `sector_codes`
- `POST /api/import-snapshot`：导入结构化快照，不接受截图解析；字段示例：

```json
{
  "rows": [
    {
      "trade_date": "2026-08-20",
      "sector_type": "concept",
      "sector_code": "880729",
      "sector_name": "CXO概念",
      "rank": 1,
      "rps50": 98,
      "pct_change": 5.26,
      "close": 1051.9,
      "amount": 773800000000
    }
  ]
}
```

  `amount` 按上游提供的原始单位保存，不会自动换算；同一日期和板块出现重复行会拒绝整批导入。
- `GET /api/report?sector_type=concept`
- `POST /api/llm-report`
- `GET /api/quote?symbols=000001,600000`
- `GET /api/realtime-board?sector_type=concept&limit=50`
- `GET /api/sector-capital-flow?sector_type=concept&limit=50`：读取东方财富公开板块资金流向（主力、超大单、大单、中单、小单）
- `POST /api/sector-constituents`：传入 `sector_type`、`sector_code`、`sector_name`，返回板块成分股和 ETF
- `POST /api/formula-screen`：传入 `formula`、`timeframe`（`5m`/`15m`/`30m`/`60m`/`daily`/`weekly`）和 `max_results`，执行预置公式
- `GET /api/network-diagnose`：测试东方财富和同花顺公共目录接口
- `POST /api/clear`：`{"sector_type":"concept"}`、`industry` 或 `all`

### 收盘后后台同步（可选）

网页关闭后仍想让本地服务在收盘后自动同步，可以在 `.env` 增加：

```dotenv
AUTO_CLOSE_SYNC=true
AUTO_CLOSE_SYNC_TIME=15:05
AUTO_CLOSE_SYNC_TYPES=concept,industry
```

后台任务只在本地服务运行期间生效；如果希望电脑关机后也同步，需要用 Windows 任务计划程序启动 `start.ps1`。

### efinance 超时边界

efinance 的原始全市场快照和历史接口没有可靠的超时控制。兼容模式默认优先复用已经验证的 AkShare、逐股票行情和本地目录缓存；只有显式设置 `EFINANCE_ALLOW_SLOW_FALLBACK=1` 时，才会尝试这些可能长时间不返回的原始接口。交付环境建议保持默认值 `0`。
